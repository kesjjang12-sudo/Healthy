# 카카오 로그인 켜기 — 클릭 순서대로

카카오 개발자센터는 메뉴가 많아서 **어디를 눌러야 하는지가 제일 어렵다.**
그래서 이 문서는 설명을 줄이고 **누를 곳과 붙여넣을 값**만 순서대로 적었다.

- 걸리는 시간: 처음 하면 20~30분
- 확인일: 2026-08-18 (카카오 공식 문서 기준)
- 필요한 것: 카카오계정, Supabase 대시보드 로그인
- **사업자등록번호 필요 없음** (아래 4단계에서 이메일만 안 받으면 된다)

> 앱 코드는 이미 다 되어 있다. 여기 설정만 끝나면 **앱을 다시 배포하지 않아도**
> 그 순간부터 카카오 버튼이 동작한다.

---

> ⚠️ **2026년 8월, 카카오가 콘솔 메뉴를 개편했습니다.**
> 인터넷에 도는 옛날 설명(`제품 설정 → 카카오 로그인 → 보안`)은 이제 안 맞습니다.
> **보안 메뉴는 없어졌고**, 클라이언트 시크릿은 `앱 → 플랫폼 키 → REST API 키`
> 안으로 들어갔습니다. 아래는 개편된 화면 기준입니다.

| 옛날 위치 (인터넷 설명) | 지금 위치 |
|---|---|
| 제품 설정 → 카카오 로그인 → **보안** | 앱 → 플랫폼 키 → **REST API 키** 안 |
| 제품 설정 → 카카오 로그인 → Redirect URI | 앱 → 플랫폼 키 → **REST API 키** 안 |
| 앱 설정 → 앱 키 | 앱 → **플랫폼 키** |
| 제품 설정 → 카카오 로그인 → 활성화 설정 | **카카오 로그인** → 사용 설정 |

---

## 붙여넣을 값 (미리 복사해 두면 편하다)

| 이름 | 값 | 어디에 |
|---|---|---|
| **값 B. 리다이렉트 URI** | `https://hhjmhdxcxjuhhhgjsilu.supabase.co/auth/v1/callback` | 3단계 |
| **값 C. 앱 이름** | `헬스반장` | 1단계 |

> 예전 안내에 있던 "사이트 도메인" 등록은 개편된 콘솔에서 별도 단계로 나오지
> 않는다. 리다이렉트 URI 만 등록하면 된다. 혹시 화면에 도메인 칸이 보이면
> `https://hhjmhdxcxjuhhhgjsilu.supabase.co` 를 넣으면 된다.

# 1단계 — 앱 만들기

1. <https://developers.kakao.com/console/app> 접속
2. 카카오계정으로 **로그인**
3. **애플리케이션 추가하기**

| 칸 | 넣을 값 |
|---|---|
| 앱 이름 | **헬스반장** |
| 사업자명 | **본인 이름 또는 상호** |
| 카테고리 | 건강 |

> ⚠️ **사업자명은 로그인할 때 회원 화면에 그대로 뜬다.**
> "○○○의 서비스가 회원님의 정보를 요청합니다" 로 보이니 아무거나 넣지 말 것.

만든 앱을 클릭해서 들어간다. 이제부터 **왼쪽 메뉴**를 쓴다.

---

# 2단계 — 카카오 로그인 켜기

**왼쪽 메뉴 → 카카오 로그인 → 사용 설정**

- **상태**를 **ON** 으로

> 이걸 먼저 켜야 동의항목 같은 하위 메뉴가 제대로 열린다.

---

# 3단계 — 리다이렉트 URI 등록 ⚠️ 여기가 새로 바뀐 곳

**왼쪽 메뉴 → 앱 → 플랫폼 키 → REST API 키**

이 화면 안에 **리다이렉트 URI** 칸이 있다. (예전엔 카카오 로그인 메뉴에 있었다)

**값 B** 를 붙여넣고 저장:

```
https://hhjmhdxcxjuhhhgjsilu.supabase.co/auth/v1/callback
```

> 우리 앱 주소(`fitroutine://` 나 `github.io`)를 넣는 게 **아니다.**
> 카카오는 Supabase 로 보내고, Supabase 가 우리 앱으로 되돌린다.

---

# 4단계 — 동의항목 ⚠️ 이메일은 절대 켜지 말 것

**왼쪽 메뉴 → 카카오 로그인 → 동의항목**

| 항목 | 어떻게 |
|---|---|
| 닉네임 | **필수 동의** |
| 프로필 사진 | 필수 동의 (또는 선택 동의) |
| **카카오계정(이메일)** | ❌ **건드리지 말 것** |
| 성별·연령대·생일·전화번호 | ❌ 건드리지 말 것 |

> **왜 이메일을 켜면 안 되나**
> 이메일을 받으려면 **비즈앱 전환**이 필요하고, 비즈앱은 **사업자등록번호**가
> 있어야 한다. 심사도 받아야 한다.
> 우리 앱은 이메일을 쓰는 기능이 하나도 없다 — 회원 구분은 전화번호로 한다.
> **이메일만 안 켜면 사업자등록도 심사도 없이 바로 쓸 수 있다.**

---

# 5단계 — 키 2개 복사하기 (한 화면에 다 있다)

**왼쪽 메뉴 → 앱 → 플랫폼 키 → REST API 키**

3단계에서 갔던 그 화면이다. 여기서 두 가지를 가져간다.
**메모장에 붙여 두면 편하다.**

### 키 ①  REST API 키 값

화면에 보이는 **REST API 키** 값을 복사한다.

> 왼쪽 메뉴에 JavaScript 키·네이티브 앱 키·어드민 키도 있는데 **쓰지 않는다.**
> 특히 **어드민 키는 절대 아무 데도 넣지 말 것** (모든 권한을 가진 키다).

### 키 ②  클라이언트 시크릿  ← 옛날 "보안" 페이지에 있던 것

같은 **REST API 키** 화면 안에 **클라이언트 시크릿** 항목이 있다.

1. **코드 생성** 선택
2. 화면 **우측 하단의 저장** 을 눌러야 코드가 실제로 발급된다 ⚠️
3. **활성화** 를 **ON** 으로 바꾸고 다시 **저장** ⚠️

> 생성만 하고 **저장·활성화를 안 하면** 나중에 로그인이 실패한다.
> 카카오 공식 문서 기준으로 저장을 두 번(생성 후, 활성화 후) 눌러야 한다.

---

# 6단계 — Supabase 에 키 넣기 (카카오 사이트 아님)

<https://supabase.com/dashboard> 접속 → 우리 프로젝트 선택

**왼쪽 메뉴 → Authentication → Sign In / Providers → Kakao**

| 칸 | 넣을 값 |
|---|---|
| Enabled | **ON** |
| Client ID | 5단계 **키 ①** (REST API 키) |
| Client Secret | 5단계 **키 ②** |
| **Allow users without an email** | **ON** ⚠️ |

> 이메일을 안 받기로 했으므로 **Allow users without an email 을 반드시 켜야**
> 한다. 안 켜면 "이메일이 없다"며 로그인이 실패한다.

**Save**

---

# 7단계 — 복귀 주소 허용 (Supabase, 여기서도 자주 막힘)

같은 Supabase 대시보드에서:

**Authentication → URL Configuration → Redirect URLs**

**Add URL** 로 아래 둘을 각각 추가:

```
fitroutine://auth-callback
```
```
https://kesjjang12-sudo.github.io/Healthy/auth-callback
```

> 앞의 것은 설치한 앱, 뒤의 것은 웹(인터넷 주소로 쓰는 경우)이다.
> `fitroutine` 은 옛 이름이지만 **바꾸면 안 된다** — 기구 QR 코드가 이 이름을 쓴다.

---

# 8단계 — 됐는지 확인

제가 확인해 드릴 수 있습니다. 대화창에 이렇게만 보내 주세요:

```
카카오 로그인 설정 다 했어. 서버에 켜졌는지 확인해줘.
```

직접 확인하시려면 앱에서 카카오 버튼을 눌러 보세요.

| 화면에 뜨는 것 | 뜻 |
|---|---|
| 카카오 로그인 창이 뜬다 | ✅ 성공 |
| "카카오 로그인이 아직 준비되지 않았습니다" | 6단계 Enabled 가 꺼져 있음 |
| `invalid redirect` / `KOE006` | 3단계 리다이렉트 URI 오타 |
| `KOE101` / 앱 키 오류 | 5단계에서 REST API 키가 아닌 다른 키를 넣음 |
| 로그인은 되는데 앱으로 안 돌아옴 | 7단계 Redirect URLs 누락 |

---

# 자주 나는 오류 4가지

**1. "보안" 메뉴가 안 보인다**
→ 정상이다. 없어졌다. 클라이언트 시크릿은 **앱 → 플랫폼 키 → REST API 키**
   화면 안에 있다 (5단계).

**2. `KOE006 - 등록되지 않은 Redirect URI`**
→ 3단계 값에 오타. 앞뒤 공백, `http`/`https`, 끝의 `/` 까지 정확히 맞아야 한다.
값 B 를 다시 복사해서 붙여넣기.

**3. 로그인 창은 뜨는데 마지막에 실패한다**
→ 5단계 키 ② 클라이언트 시크릿의 **활성화**가 OFF 이거나, **저장**을 안 눌러
   코드가 실제로 발급되지 않았을 가능성이 높다.

**4. "이메일이 필요합니다" 같은 오류**
→ 6단계 **Allow users without an email** 이 꺼져 있다.

# 나중에 할 일 (지금 안 해도 됨)

- **버튼 이미지** — 지금 카카오 버튼의 말풍선 그림은 규정 수치에 맞춰 직접
  그린 것이고 공식 파일이 아니다. 출시 전에
  <https://developers.kakao.com/tool/resource/login> 에서 공식 이미지를 받아
  교체하는 게 안전하다. (그 페이지는 카카오 로그인이 있어야 열려서 제가
  대신 받을 수 없다.)
- **구글 로그인** — 절차가 거의 같다. Google Cloud Console 에서 OAuth
  클라이언트(웹)를 만들고, 승인된 리디렉션 URI 에 **값 B 를 똑같이** 넣은 뒤
  Supabase 의 Google 칸에 ID/Secret 을 넣으면 된다.
