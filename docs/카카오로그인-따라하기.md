# 카카오 로그인 켜기 — 클릭 순서대로

카카오 개발자센터는 메뉴가 많아서 **어디를 눌러야 하는지가 제일 어렵다.**
그래서 이 문서는 설명을 줄이고 **누를 곳과 붙여넣을 값**만 순서대로 적었다.

- 걸리는 시간: 처음 하면 20~30분
- 필요한 것: 카카오계정, Supabase 대시보드 로그인
- **사업자등록번호 필요 없음** (아래 4단계에서 이메일만 안 받으면 된다)

> 앱 코드는 이미 다 되어 있다. 여기 설정만 끝나면 **앱을 다시 배포하지 않아도**
> 그 순간부터 카카오 버튼이 동작한다.

---

## 붙여넣을 값 3개 (미리 복사해 두면 편하다)

| 이름 | 값 |
|---|---|
| **A. 사이트 도메인** | `https://hhjmhdxcxjuhhhgjsilu.supabase.co` |
| **B. Redirect URI** | `https://hhjmhdxcxjuhhhgjsilu.supabase.co/auth/v1/callback` |
| **C. 앱 이름** | `헬스반장` |

A 와 B 는 **비슷하게 생겼지만 다른 값이다.** 넣는 자리도 다르다. 헷갈리면
아래 표를 다시 볼 것.

---

# 1단계 — 앱 만들기

1. <https://developers.kakao.com> 접속
2. 오른쪽 위 **로그인** (카카오계정으로)
3. 위쪽 메뉴 **내 애플리케이션** 클릭
4. **애플리케이션 추가하기** 버튼

입력할 것:

| 칸 | 넣을 값 |
|---|---|
| 앱 아이콘 | 안 넣어도 됨 (나중에 가능) |
| 앱 이름 | **헬스반장** |
| 사업자명 | **본인 이름 또는 상호** |
| 카테고리 | 건강 |

> ⚠️ **사업자명은 로그인할 때 회원 화면에 그대로 뜬다.**
> "홍길동님의 서비스가 회원님의 정보를 요청합니다" 이런 식으로 보이니
> 아무거나 넣지 말 것.

**저장** 누르면 앱이 만들어진다.

---

# 2단계 — 사이트 도메인 등록 ⚠️ 이걸 빼먹으면 3단계가 저장 안 된다

만든 앱을 클릭해서 들어간 다음:

**왼쪽 메뉴 → 앱 설정 → 플랫폼**

1. **Web 플랫폼 등록** 버튼 (Android/iOS 말고 **Web**)
2. 사이트 도메인에 **값 A** 붙여넣기:

```
https://hhjmhdxcxjuhhhgjsilu.supabase.co
```

3. 저장

> 여기 등록한 도메인에 속한 주소만 3단계에서 받아 준다. 순서를 바꾸면
> 3단계에서 "저장할 수 없다"는 오류가 난다.

---

# 3단계 — 카카오 로그인 켜고 Redirect URI 넣기

**왼쪽 메뉴 → 제품 설정 → 카카오 로그인**

1. 맨 위 **활성화 설정** 을 **ON** 으로
2. 같은 화면 아래쪽 **Redirect URI** → **등록** 버튼
3. **값 B** 를 붙여넣기 (끝에 `/auth/v1/callback` 이 붙는 쪽):

```
https://hhjmhdxcxjuhhhgjsilu.supabase.co/auth/v1/callback
```

4. 저장

### 여기서 제일 많이 헷갈리는 것

| | 넣는 곳 | 값 |
|---|---|---|
| 2단계 | 앱 설정 → 플랫폼 → **사이트 도메인** | 짧은 쪽 (`.co` 로 끝남) |
| 3단계 | 카카오 로그인 → **Redirect URI** | 긴 쪽 (`/auth/v1/callback` 붙음) |

우리 앱 주소(`fitroutine://` 나 `github.io`)를 넣는 게 **아니다.**
카카오는 Supabase 로 보내고, Supabase 가 우리 앱으로 되돌린다.

---

# 4단계 — 동의항목 ⚠️ 이메일은 절대 켜지 말 것

**왼쪽 메뉴 → 제품 설정 → 카카오 로그인 → 동의항목**

| 항목 | 어떻게 |
|---|---|
| 닉네임 | **필수 동의** 로 설정 |
| 프로필 사진 | 필수 동의 (또는 선택 동의) |
| **카카오계정(이메일)** | ❌ **건드리지 말 것** |
| 그 외 전부 (성별·연령대·생일·전화번호) | ❌ 건드리지 말 것 |

> **왜 이메일을 켜면 안 되나**
> 이메일을 받으려면 **비즈앱 전환**이 필요하고, 비즈앱은 **사업자등록번호**가
> 있어야 한다. 심사도 받아야 한다.
> 우리 앱은 이메일을 쓰는 기능이 하나도 없다 — 회원 구분은 전화번호로 한다.
> **이메일만 안 켜면 사업자등록도 심사도 없이 바로 쓸 수 있다.**

---

# 5단계 — 키 2개 복사하기

여기서 복사한 값을 6단계에 넣는다. **메모장에 붙여 두면 편하다.**

### 키 ①  REST API 키

**왼쪽 메뉴 → 앱 설정 → 앱 키**

키가 4개 보인다. 그중 **REST API 키** 만 복사한다.

| 키 이름 | 쓰나? |
|---|---|
| 네이티브 앱 키 | ❌ |
| **REST API 키** | ✅ **이것** |
| JavaScript 키 | ❌ |
| Admin 키 | ❌ (남에게 절대 주면 안 되는 키) |

### 키 ②  Client Secret

**왼쪽 메뉴 → 제품 설정 → 카카오 로그인 → 보안**

1. **코드 생성** 버튼 → 생성된 코드 복사
2. 바로 밑 **활성화 상태** 를 **사용함** 으로 바꾸기 ⚠️

> 생성만 하고 **활성화를 안 켜면** 나중에 로그인이 실패한다.
> 이게 두 번째로 흔한 실수다.

---

# 6단계 — Supabase 에 키 넣기 (카카오 사이트 아님)

<https://supabase.com/dashboard> 접속 → 우리 프로젝트 선택

**왼쪽 메뉴 → Authentication → Sign In / Providers → Kakao**

| 칸 | 넣을 값 |
|---|---|
| Enabled | **ON** |
| Client ID | 5단계 **키 ①** (REST API 키) |
| Client Secret | 5단계 **키 ②** |
| **Allow users without an email** | **ON** ⚠️ |

> 이메일을 안 받기로 했으므로 **Allow users without an email 을 반드시 켜야**
> 한다. 안 켜면 "이메일이 없다"며 로그인이 실패한다.

**Save**

---

# 7단계 — 복귀 주소 허용 (Supabase, 여기서도 자주 막힘)

같은 Supabase 대시보드에서:

**Authentication → URL Configuration → Redirect URLs**

**Add URL** 로 아래 둘을 각각 추가:

```
fitroutine://auth-callback
```
```
https://kesjjang12-sudo.github.io/Healthy/auth-callback
```

> 앞의 것은 설치한 앱, 뒤의 것은 웹(인터넷 주소로 쓰는 경우)이다.
> `fitroutine` 은 옛 이름이지만 **바꾸면 안 된다** — 기구 QR 코드가 이 이름을 쓴다.

---

# 8단계 — 됐는지 확인

제가 확인해 드릴 수 있습니다. 대화창에 이렇게만 보내 주세요:

```
카카오 로그인 설정 다 했어. 서버에 켜졌는지 확인해줘.
```

직접 확인하시려면 앱에서 카카오 버튼을 눌러 보세요.

| 화면에 뜨는 것 | 뜻 |
|---|---|
| 카카오 로그인 창이 뜬다 | ✅ 성공 |
| "카카오 로그인이 아직 준비되지 않았습니다" | 6단계 Enabled 가 꺼져 있음 |
| `invalid redirect` / `KOE006` | 3단계 Redirect URI 오타 |
| `KOE101` / 앱 키 오류 | 5단계에서 REST API 키가 아닌 다른 키를 넣음 |
| 로그인은 되는데 앱으로 안 돌아옴 | 7단계 Redirect URLs 누락 |

---

# 자주 나는 오류 4가지

**1. 3단계에서 Redirect URI 가 저장이 안 된다**
→ 2단계(사이트 도메인)를 안 했거나 오타. 2단계부터 다시.

**2. `KOE006 - 등록되지 않은 Redirect URI`**
→ 3단계 값에 오타. 앞뒤 공백, `http`/`https`, 끝의 `/` 까지 정확히 맞아야 한다.
값 B 를 다시 복사해서 붙여넣기.

**3. 로그인 창은 뜨는데 마지막에 실패한다**
→ 5단계 키 ② 의 **활성화 상태**가 "사용 안 함"으로 되어 있을 가능성이 높다.

**4. "이메일이 필요합니다" 같은 오류**
→ 6단계 **Allow users without an email** 이 꺼져 있다.

---

# 나중에 할 일 (지금 안 해도 됨)

- **버튼 이미지** — 지금 카카오 버튼의 말풍선 그림은 규정 수치에 맞춰 직접
  그린 것이고 공식 파일이 아니다. 출시 전에
  <https://developers.kakao.com/tool/resource/login> 에서 공식 이미지를 받아
  교체하는 게 안전하다. (그 페이지는 카카오 로그인이 있어야 열려서 제가
  대신 받을 수 없다.)
- **구글 로그인** — 절차가 거의 같다. Google Cloud Console 에서 OAuth
  클라이언트(웹)를 만들고, 승인된 리디렉션 URI 에 **값 B 를 똑같이** 넣은 뒤
  Supabase 의 Google 칸에 ID/Secret 을 넣으면 된다.
