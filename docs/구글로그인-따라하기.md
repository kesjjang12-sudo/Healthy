# 1단계 — 구글 클라우드 프로젝트 만들기

1. <https://console.cloud.google.com> 접속 (구글 계정 로그인)
2. 화면 위쪽 **프로젝트 선택** → **새 프로젝트**
3. 프로젝트 이름: `헬스반장` → **만들기**
4. 만들어지면 그 프로젝트가 선택돼 있는지 확인

# 3단계 — 게시 상태를 "프로덕션"으로

같은 **OAuth 동의 화면**의 **게시 상태** 항목:

- **테스트** 상태면 미리 등록한 테스트 사용자만 로그인된다 (최대 100명)
- **프로덕션**으로 바꾸면 누구나 로그인할 수 있다

**앱 게시(PUBLISH APP)** 를 눌러 **프로덕션**으로 바꾼다.

> 기본 정보(이메일·이름·프로필 사진)만 받으므로 **구글 심사(verification)는
> 필요 없다.** 심사는 Gmail·드라이브 같은 민감 권한을 요청할 때만 걸린다.
> 게시할 때 "확인이 필요하지 않습니다" 같은 안내가 나오면 정상이다.

---

# 4단계 — OAuth 클라이언트 만들기

왼쪽 메뉴 **API 및 서비스 → 사용자 인증 정보(Credentials)**

1. 위쪽 **+ 사용자 인증 정보 만들기** → **OAuth 클라이언트 ID**
2. **애플리케이션 유형: 웹 애플리케이션** ⚠️ (Android 아님)

> **왜 Android 가 아니라 웹인가**
> 우리 앱은 구글 SDK 를 직접 쓰지 않는다. Supabase 가 대신 구글과 주고받고,
> 그 Supabase 주소가 웹 주소이기 때문이다. Android 를 고르면 리디렉션 URI 를
> 넣는 칸 자체가 안 나온다.

3. 이름: `헬스반장 웹` (아무거나)
4. **승인된 리디렉션 URI** → **+ URI 추가**:

```
https://hhjmhdxcxjuhhhgjsilu.supabase.co/auth/v1/callback
```

5. **만들기**

만들면 **클라이언트 ID** 와 **클라이언트 보안 비밀번호**가 뜬다.
**둘 다 복사해 둔다** (창을 닫아도 나중에 다시 볼 수 있다).

# 5단계 — Supabase 에 넣기

<https://supabase.com/dashboard> → 우리 프로젝트

**Authentication → Sign In / Providers → Google**

| 칸 | 넣을 값 |
|---|---|
| Enable Sign in with Google | **ON** |
| Client ID | 4단계 **클라이언트 ID** |
| Client Secret | 4단계 **클라이언트 보안 비밀번호** |

**Save**

> 복귀 주소(Redirect URLs)는 카카오 때 이미 넣어 뒀으므로 다시 안 해도 된다.
> (`fitroutine://auth-callback`, `https://kesjjang12-sudo.github.io/Healthy/auth-callback`)

# 6단계 — 확인

대화창에 이렇게 보내면 제가 서버에 물어봐 확인해 드린다:

```
구글 로그인 설정 다 했어. 서버에 켜졌는지 확인해줘.
```

직접 확인하시려면 앱에서 구글 버튼을 눌러 본다.

| 화면에 뜨는 것 | 뜻 |
|---|---|
| 구글 계정 선택 창이 뜬다 | ✅ 성공 |
| 구글 버튼이 아예 안 보인다 | 5단계 Enable 이 꺼져 있음 (앱을 다시 열어 볼 것) |
| `redirect_uri_mismatch` | 4단계 리디렉션 URI 오타 |
| "이 앱은 확인되지 않았습니다" | 3단계 게시 상태가 **테스트**로 남아 있음 |
| 로그인은 되는데 앱으로 안 돌아옴 | Supabase Redirect URLs 누락 |

---

# 자주 나는 오류

**1. `redirect_uri_mismatch`**
→ 4단계 값에 오타. 끝의 `/callback` 까지, 앞뒤 공백 없이 정확해야 한다.
   구글은 **완전히 같은 문자열**만 받는다.

**2. "이 앱은 Google에서 확인하지 않았습니다" 경고**
→ 3단계에서 **프로덕션**으로 게시하지 않았다. 테스트 상태면 등록한 테스트
   사용자 외에는 이 경고를 본다.

**3. 리디렉션 URI 넣는 칸이 안 보인다**
→ 4단계에서 애플리케이션 유형을 **웹 애플리케이션**이 아닌 다른 걸로 골랐다.
   클라이언트를 지우고 다시 만든다.

**4. 구글 버튼이 앱에 안 나타난다**
→ 앱이 로그인 화면을 열 때 한 번만 서버에 물어보고 그 결과를 기억한다.
   앱을 완전히 껐다 켜거나, 웹이면 새로고침할 것.

## 카카오와 뭐가 다른가

| | 구글 | 카카오 |
|---|---|---|
| 사업자등록 | 필요 없음 | 이메일·전화번호 받으려면 필요 |
| 심사 | 없음 (기본 정보만 받으면) | 전화번호는 3~5 영업일 |
| 전화번호 | **못 받음** | 비즈앱 + 심사 후 가능 |

> 구글로는 전화번호를 못 받는다. 구글로 가입한 회원은 키오스크 매칭을 위해
> **문자 인증이나 QR 페어링**으로 번호를 따로 연결해야 한다. 이건 이미
> 만들어져 있는 경로다.
