# Claude Code 스킬 설치 프롬프트

새 세션에 아래 블록을 그대로 붙이면 이 저장소에서 쓰는 스킬이 한 번에 설치된다.
스킬(문서)은 `.claude/skills/` 에 커밋돼 있어 main 에 들어간 뒤로는 1번이 필요 없다.
agent-reach 는 프로그램이라 세션마다 다시 깔아야 한다 — 매번 하기 싫으면
세션 제목 바의 환경 메뉴 → Edit → Setup script 에 2번 명령을 넣어 둔다.

```
Claude Code 스킬을 이 저장소에 설치해 줘. 권한 물으면 내가 허용할 테니 멈추지 말고 진행해.

1. 스킬 설치 (프로젝트 단위, 복사본으로):
   npx -y skills@latest add obra/superpowers -y -a claude-code -s '*' --copy
   npx -y skills@latest add anthropics/skills -y -a claude-code -s frontend-design --copy
   npx -y skills@latest add dietrichgebert/ponytail -y -a claude-code -s '*' --copy

2. 인터넷 읽기 도구 agent-reach (이 세션용):
   python3 -m pip install -q --user pipx
   export PATH="$HOME/.local/bin:$PATH"
   python3 -m pipx install --backend pip git+https://github.com/Panniantong/agent-reach.git
   python3 -m pip install -q --user "yt-dlp[default]"
   agent-reach skill --install
   (깃허브 zip 주소는 프록시가 403으로 막으니 꼭 git+ 방식으로)

3. .claude/skills/ 와 skills-lock.json 을 커밋하고 현재 브랜치에 푸시해.
   main 에는 내가 깃허브에서 직접 병합할 거니까 main 푸시는 하지 마.

4. 끝나면 설치된 스킬 목록을 표로 보여 줘.
```

## 설치되는 것

| 묶음 | 개수 | 하는 일 |
| --- | --- | --- |
| superpowers (obra) | 15 | 요구사항 정리(brainstorming), 원인부터 찾는 디버깅, 테스트 먼저, 끝났다고 말하기 전 검증, 계획 세우기·실행 |
| frontend-design (Anthropic) | 1 | UI 만들 때 뻔한 "AI 디자인" 안 나오게 |
| ponytail | 6 | 코드 최소화(YAGNI). `/ponytail-review` 로 과한 코드 삭제 목록 |
| agent-reach | 프로그램 | 웹페이지·RSS·유튜브 자막 읽기. 세션마다 재설치 필요 |

## 안 되는 것 / 로컬 전용

- **graphify**: 코드 관계도. 원하면 2번 아래에
  `pip install graphifyy && graphify install --project --platform claude` 추가.
- **headroom**, **OmniRoute**: 컴퓨터에서 Claude Code 를 직접 돌릴 때만 의미 있는
  프록시 도구. 클라우드 세션에는 적용 불가.
