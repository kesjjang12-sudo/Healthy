# 카카오 개인정보 동의항목 신청서 — 채워 넣을 내용

`앱 → 추가 기능 신청 → 개인정보 동의항목 → 신청` 창에 그대로 복사해 넣을
내용을 모아 둔 파일이다. 신청 창은 칸이 네 개다.

| 칸 | 준비 상태 |
|---|---|
| 개인정보 처리방침 URL | ✅ 아래 값 |
| 회원가입 화면 (파일 첨부) | ⚠️ 아래 둘 중 하나 |
| 수집 사유 | ✅ 아래 문구 |
| 신청 항목 선택 | ✅ 아래 표 |

> ⛔ **먼저 할 일이 하나 있다.** 처리방침에 회사 정보가 아직 안 채워져 있다.
> 그대로 내면 심사에서 "[미입력: 대표자명]" 이 보인다 — 맨 아래 참고.

## 2. 회원가입 화면 (파일 첨부)

신청 창 안내: **최대 1장 / 20MB 이내 / JPG·JPEG·PNG·PDF**,
개인정보가 보이면 **마스킹 필수**(안 하면 반려).

두 가지 중 편한 쪽:

### 방법 ① 실제 화면 캡처 (권장)

폰에서 앱을 **로그아웃 상태**로 열고, **동의 화면**을 캡처한다.
(로그인 → 카카오/문자 선택 → 동의 화면)

캡처에 본인 전화번호·이름이 보이면 그 부분을 까맣게 칠할 것.

### 방법 ② 시나리오로 대체 (캡처가 어려우면)

아래 글을 그대로 복사해 **PDF 나 이미지로 만들어** 첨부한다.
(메모장에 붙여넣고 인쇄 → PDF 저장이면 된다)

```
헬스반장 회원가입 및 동의 시나리오

1. 앱 실행 → 로그인 화면
   - "카카오 로그인" / "문자로 로그인" 중 선택

2. 카카오 로그인 선택 시
   - 카카오 동의 화면에서 아래 항목에 동의
     · 닉네임 (필수)
     · 카카오계정(이메일) (필수)
     · 카카오계정(전화번호) (필수)

3. 서비스 이용약관·개인정보 처리방침 동의 화면
   - 이용약관 동의 (필수)
   - 개인정보 수집·이용 동의 (필수)
   - 건강정보(운동 기록) 수집 동의 (필수, 별도 동의)
   - 아프거나 불편한 부위 수집 동의 (선택)
   - 각 항목마다 "전문 보기"로 원문을 확인할 수 있음

4. 최초 설문
   - 성별, 연령대, 운동 목적 선택
   - 아프거나 불편한 부위 선택 (선택 동의한 경우에만)

5. 가입 완료 → 운동 화면
```

## 3. 수집 사유 (그대로 복사)

### 카카오계정(전화번호)

```
헬스장 입구에 설치된 키오스크(태블릿)에서 회원을 확인하기 위해 전화번호가 필요합니다.

회원은 헬스장에 도착해 키오스크에 전화번호를 입력하여 출석을 기록하고, 개인 휴대폰의 앱에서 같은 계정으로 자신의 운동 기록을 확인합니다. 두 기기에서 같은 회원임을 알아보는 기준이 전화번호입니다.

카카오 로그인으로 가입한 회원의 전화번호를 확보하지 못하면, 키오스크에서 출석을 찍어도 앱의 계정과 연결되지 않아 운동 기록이 남지 않습니다. 이를 위해 별도의 전화번호 입력 단계를 추가하면 4060 세대 이용자에게 가입 이탈이 발생합니다.

수집한 전화번호는 회원 식별과 출석 기록 연결에만 사용하며, 마케팅·광고에 이용하거나 제3자에게 제공하지 않습니다.
```

### 카카오계정(이메일)

```
회원 계정을 식별하기 위해 사용합니다.

본 서비스는 인증 시스템으로 Supabase Auth 를 사용하며, 이 시스템이 소셜 로그인 계정을 생성할 때 이메일을 계정 식별자로 요구합니다.

이메일은 계정 식별 용도로만 사용하며, 메일 발송·마케팅에 이용하지 않습니다.
```

> 심사에 적는 이용 목적은 **실제 동작과 같아야 한다.** 위 문구는 이 저장소의
> 실제 구현(키오스크 전화번호 매칭, Supabase Auth)에 맞춰 쓴 것이다.

# ⛔ 신청 전에 반드시 채워야 할 것 — 회사 정보 13개

지금 처리방침을 열면 **"[미입력: 대표자명]"** 처럼 빈칸이 그대로 보인다.
이 상태로 심사에 내면 반려된다. 그리고 개인정보 보호법 제30조·제31조상
보호책임자와 연락처 공개는 **의무**라, 비워 두면 방침 자체가 요건 미달이다.

`src/features/legal/company.ts` 한 파일만 고치면 약관·방침·동의 화면이
한꺼번에 바뀐다. 아래 값을 알려주시면 제가 넣겠다.

| 항목 | 설명 |
|---|---|
| 대표자명 | 사업자등록증상 대표자 |
| 사업자등록번호 | 000-00-00000 |
| 사업장 주소 | 사업자등록증상 주소 |
| 문의 이메일 | 이용자 문의를 받을 주소 |
| 문의 전화번호 | 이용자 문의를 받을 번호 |
| 보호책임자 성명 | 개인정보 보호책임자 (대표자 본인이어도 됨) |
| 보호책임자 직위 | 예: 대표 |
| 보호책임자 이메일 | |
| 보호책임자 전화번호 | |
| 담당 부서 | 예: 고객지원 (1인이면 "대표") |
| 담당 부서 이메일 | |
| 담당 부서 전화번호 | |
| 관할 법원 소재지 | 예: 서울중앙지방법원 |

> 문의 이메일·전화번호는 **공개되는 값**이다. 개인 번호를 넣기 부담스러우면
> 업무용 번호나 이메일을 따로 준비하는 편이 낫다.

**추가로 하나 더** — 처리방침에 `{{데이터 저장 리전 국가}}` 가 남아 있다.
Supabase 프로젝트의 저장 리전을 확인해서 채워야 한다. 제가 확인해 드릴 수 있다.

## 방침에 이미 반영해 둔 것

전화번호 수집 출처에 **소셜 로그인(카카오)** 을 추가했다. 원래는 "키오스크에서
직접 입력"만 적혀 있었는데, 카카오에서 받기 시작하면 방침과 실제가 어긋나므로
미리 맞춰 뒀다. 심사에서도 방침과 신청 내용이 일치해야 한다.
