# 플레이스토어 출시 절차 (2026-08 기준)

앱 쪽 준비는 끝나 있다 — 패키지명 `com.fitroutine.app`, 아이콘·스플래시,
EAS 프로젝트(health-leader 조직), 개인정보처리방침 공개 URL까지. 아래에서
오너가 눌러야 하는 것만 순서대로 적는다.

## 0. 준비물

- 구글 계정, 등록비 $25(1회), 신분증(본인 인증), 결제 카드
- 노트북 (2단계 빌드 명령 1개 실행)

## 1. 구글 플레이 개발자 등록

https://play.google.com/console → 가입.

**개인 vs 사업자(조직)** — 중요한 갈림길:
- **개인 계정**: 바로 만들 수 있지만, 프로덕션(정식 출시) 전에 **비공개
  테스트를 일정 인원·기간 채워야 하는 요건**이 붙는다(콘솔이 정확한 인원·
  기간을 안내해 준다. 지인 폰 여러 대로 채우면 된다).
- **조직(사업자) 계정**: 사업자등록 + DUNS 번호가 필요해 시작이 느리지만
  테스트 요건이 면제라 정식 출시가 빠르다.

지금 1호 단지 파일럿 단계면 **개인 계정 + 비공개 테스트**가 오히려 자연스럽다
— 어차피 테스트 사용자(단지 주민)에게 먼저 깔게 할 것이기 때문.

## 2. 앱 빌드 (.aab 만들기)

노트북 터미널에서 저장소 받은 뒤:

```bash
npm install
npx eas build --platform android --profile production
```

- Expo 로그인 창이 뜨면 health-leader 조직에 속한 계정으로 로그인.
- 서명 키는 "EAS가 관리"를 선택(기본값). 직접 보관할 필요 없다.
- 20~30분 뒤 빌드가 끝나면 링크에서 `.aab` 파일을 내려받는다.

이 빌드에는 알림 모듈(expo-notifications)이 포함된다. 설치해서 확인한 뒤
`src/features/notifications/cardio-alarm.ts` 의 `NATIVE_ALARM_READY` 를
true 로 바꾸면 운동 리마인더·유산소 알림이 살아난다(주석의 사고 이력 참고 —
반드시 새 빌드를 실제 기기에서 확인한 뒤 켤 것).

그다음 콘솔이 시키는 항목들. 붙여넣을 값:

- **개인정보처리방침 URL**:
  `https://kesjjang12-sudo.github.io/Healthy/legal/privacy`

- **스토어 등록정보**: `docs/store-listing.md` 의 문구를 복사해 붙인다.
